# Tripartite Synapse Expansion

The iMAT cell-specific models (iMMU1867a and iMMU1867n) were extended to represent the tripartite synapse (TPS). The astrocyte model was expanded with the perisynaptic astrocytic process (PAP), the neuron model was split into pre-synaptic and post-synaptic forms, and literature-supported intercellular transport reactions were added to capture synaptic metabolism.

model_expansion_to_TPS.xlsx contains all the reactions added during the expansion including:
1. Transport and Uptake Reactions: intercellular and synaptic transport reactions added to connect the three cell types.
2. Lipid Peroxidation Workflow: the lipid peroxidation reactions added to the models

Models_expansion_building.xml: the XML file used to build the tripartite expansion - was written in Notepad++.

Models obtained: iMMU1868a-pap, iMMU1868n-pre, and iMMU1868n-post. These are in models/04_tripartite_expanded.
